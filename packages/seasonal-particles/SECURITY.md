# Security Policy

## Supported Versions

We provide security updates for the current major release of `@swagat10241/seasonal-particles`.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take security seriously. Since `@swagat10241/seasonal-particles` is a zero-dependency client-side canvas library without external supply-chain dependencies, network activity, or DOM injection risks, security vulnerabilities are rare.

However, if you discover a vulnerability (such as unintended execution contexts, prototype pollution, memory exhaustion loops, or denial of service through canvas dimension overflows), please disclose it responsibly.

### How to Report
- **DO NOT** file a public GitHub issue.
- Please email the maintainer directly at:
  **[swagatsourav10241@gmail.com](mailto:swagatsourav10241@gmail.com)** with the subject line `[SECURITY] @swagat10241/seasonal-particles`.
- Include:
  1. Description of the issue.
  2. Proof of concept or minimal reproducible code.
  3. Potential impact.

### Response Timeline
- **Acknowledgement**: Within 48 hours.
- **Remediation & Patch**: Within 7 business days.
- **Public Disclosure**: Coordinated after a patch is released to the npm registry and GitHub releases.
