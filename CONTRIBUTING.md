# Contributing

Thanks for your interest in improving this profile repository.

## What this repo is

- GitHub **profile README** (`README.md`)
- Small **browser demo** (`index.html`)
- Automation and security configuration under `.github/`

Product features for TrailGuard / SWAAS belong in
[Smart-Wearable](https://github.com/SWAGAT10241/Smart-Wearable), not here.

## How to contribute

1. Fork the repository (or open a branch if you have write access).
2. Create a focused branch: `docs/...`, `fix/...`, or `chore/...`.
3. Make your change with a clear commit message.
4. Open a Pull Request describing **what** changed and **why**.

## Guidelines

- Keep the profile README **accurate** (no inflated titles or false claims).
- Prefer small, reviewable PRs.
- Do not commit secrets, tokens, or personal credentials.
- Match existing Markdown/HTML style where reasonable.
- For security issues, follow [SECURITY.md](./SECURITY.md) — do not open a public issue.

## Development notes

- Preview the demo by opening `index.html` locally or via GitHub Pages once enabled.
- CI runs on pull requests (see `.github/workflows/`).
