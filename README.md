### Flagship — TrailGuard / SWAAS

<div align="center">

**Wearable safety & health monitoring ecosystem**

[![Repo](https://img.shields.io/badge/GitHub-Smart--Wearable-0070D1?style=for-the-badge&logo=github&logoColor=white)](https://github.com/SWAGAT10241/Smart-Wearable)
[![Live](https://img.shields.io/badge/Live-teaminfinitylabs.tech-00C853?style=for-the-badge)](https://www.teaminfinitylabs.tech/)

</div>

ESP32 wearable + Node.js backend + React dashboard for vitals, GPS, fall detection, and emergency-oriented workflows.

| Layer | Stack |
| :--- | :--- |
| **Hardware** | ESP32, biometric / motion / environment sensors, GPS |
| **Backend** | Node.js, Express, MongoDB, WebSockets, JWT, Google OAuth |
| **Frontend** | React, Vite, Tailwind, MapLibre GL |
| **Focus** | Telemetry pipeline, auth, live dashboard, testing |

> **Status:** actively developed. Capabilities depend on ongoing hardware validation — not a finished medical product.
