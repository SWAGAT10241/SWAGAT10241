# Security Policy

## Supported versions

This repository is the **GitHub profile** for `@SWAGAT10241` (README + small browser demo).

| Component | Supported |
| --- | --- |
| Profile `README.md` | Yes (content updates) |
| `index.html` demo | Best-effort |
| GitHub Actions workflows | Yes |

For application security on real products, see the project repos (e.g. [Smart-Wearable](https://github.com/SWAGAT10241/Smart-Wearable)).

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

1. Email **swagatsourav10241@gmail.com** with:
   - Description of the issue
   - Steps to reproduce (if applicable)
   - Impact assessment
   - Any suggested fix
2. You can also use **GitHub Private Vulnerability Reporting** on this repository (Security → Report a vulnerability), if enabled.

You should receive an acknowledgement within **72 hours**. We will work on a fix and coordinate disclosure when appropriate.

## Scope

In scope for this repo:

- XSS or unsafe patterns in `index.html`
- Secrets accidentally committed to this repository
- Workflow permission or supply-chain issues in `.github/`

Out of scope:

- Issues in third-party badge/stats CDNs used by the README
- Social-engineering or physical attacks
- Denial of service against GitHub.com itself

## Safe harbor

Security research conducted in good faith under this policy is appreciated. Please avoid data destruction, privacy violations, and service disruption.
