# Security Policy

## Supported

This repo hosts a **portfolio browser demo** (Vite + React) and profile assets.

| Component | Supported |
| --- | --- |
| Demo app (`src/`, build output) | Best-effort |
| GitHub Actions workflows | Yes |

Product security for real systems lives in project repos such as [Smart-Wearable](https://github.com/SWAGAT10241/Smart-Wearable).

## Reporting a vulnerability

Do **not** open a public issue for security reports.

1. Email **swagatsourav10241@gmail.com** with description, repro steps, and impact.
2. Or use GitHub **Private vulnerability reporting** if enabled on this repository.

Acknowledgement target: **72 hours**.

## Scope

**In scope:** XSS in the demo UI, secrets in git history, unsafe workflow permissions.

**Out of scope:** Third-party README badges/CDNs, social engineering, DoS against GitHub.com.
